## Highlights

- `mutantkit doctor` now runs its Xcode checks in `--project-root`, not the
  current directory. CI usually starts from the repository root, so for an
  `xcodeWorkspace`/`xcodeProject` in a subdirectory doctor found no project,
  could not list destinations, and failed `build-for-testing` with xcodebuild's
  bare exit 66.
- Schemata: never-reached mutants are proven by a new `LOADED` runtime record,
  so they are no longer reported as infrastructure errors.
- Schemata: targets resolve correctly for a package nested under `project.path`.
- Builds with Xcode 27 (`ProgressReporter` renamed to
  `MutationProgressReporter` to avoid a clash with Foundation).

## Upgrade impact

No config changes required.

## Breaking changes

None.
