# v1.0.4-fix77.3

## Fixed

- **Sandboxes can reach files next to the project root.** New opt-in setting
  `project.linkSiblings: [name, ...]`. Each named folder next to the project root
  is linked into the sandbox scratch root, so relative paths that step out of the
  project (for example a SwiftPM `.binaryTarget(path: "../../shared/App.xcframework")`)
  still resolve inside a sandbox. Before, such builds failed with exit 74 and no
  compiler diagnostic.

Includes everything in v1.0.4-fix77.2 (doctor runs in the project root).
